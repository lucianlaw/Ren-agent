# Boss Agent Core

一个跑在你本机的 agent 内核：给它一个岗位和一套人设，接上任意 OpenAI 协议的大模型，让它在一个工作目录里读文件、写文件、搜内容、跑命令。

没有登录、没有云、没有数据库。**所有数据都在你自己的机器上**，模型调用用的是你自己填的 API Key。

> ⚠️ 这个程序能读写文件、能执行 shell 命令。
> 它**只监听 `127.0.0.1`**。不要改成 `0.0.0.0`，不要把它直接暴露到公网，不要用 root 跑。
> 出问题第一件事：删掉 `data/` 目录，口令会重新生成。

## 快速开始

需要 **Node.js 18 或以上**（不需要 `npm install`，零依赖）。

```bash
git clone <这个仓库的地址>
cd boss-agent-core
node server.js
```

启动后终端会打印这样几行：

```
  打开：  http://127.0.0.1:4319
  口令：  N33Jm0uB7zN6W2Y76Fr0zIOY
```

浏览器打开那个地址，把口令粘进去，就进去了。

第一次打开是**离线 Mock 模式**：不花钱、不用 Key，模型返回是假的，但「员工 → 模型 → 工具 → 轨迹」整条链路是真的。用它先确认环境没问题。

## 接一个真模型

右上角「模型设置」→ 选服务商 → 填 API Key → 保存。

内置了几个预设（只填 Key 就行）：

| 服务商 | 说明 |
|---|---|
| DeepSeek | 便宜，适合日常跑 |
| 阿里百炼 Qwen | 国内直连，价格梯度全 |
| 智谱 GLM | 有免费档，适合调试 |
| 硅基流动 | 一个 Key 通吃几十个开源模型 |
| OpenRouter | 一个 Key 打海外模型 |
| 自定义 | 任何 OpenAI 兼容的 `/v1/chat/completions` |

Key 存在 `data/config.json`，只在本机。**别把它提交到 git**（`.gitignore` 已经挡了 `data/`）。

## 怎么用

1. 右栏「+ 新建」建一个员工：给它名字、岗位、一种说话风格，可以写一句额外交代（"报价必须含税"这种）。
2. 底部交代一件事，⌘/Ctrl + Enter 执行。
3. 中间会逐步出现它调用的每个工具：名字、参数、返回、耗时。**不是聊天记录，是执行轨迹。**

试试这几句：

- `看看工作目录里有什么，把结构说明写进 notes.md`
- `搜索 供应商报价.md 里所有含「运费」的行`
- `统计目录里所有 md 文件的行数`

## 三个权限开关

| 开关 | 开了之后它能做什么 |
|---|---|
| 读文件 | 列目录、读文件、搜内容 |
| 写文件 | 新建/覆盖工作区里的文件 |
| 跑命令 | 执行 shell（黑名单拦截 `rm -rf /`、`sudo`、`git push --force` 等） |

**默认只开「读文件」。** 需要写或跑命令时，界面上会拦下来并给一个「开启并重跑」的按钮——不是静默失败。

## 数据在哪里

```
data/           口令、会话、API Key、员工、任务轨迹（全部 gitignore）
workspace/      它唯一能碰的目录，所有路径都相对这里
```

删掉 `data/` 等于恢复出厂：口令重新生成、员工和任务清空、API Key 要重填。`workspace/` 里的文件不受影响。

## 它现在还不能做什么

说清楚比藏起来好：

- **单用户**。没有账号体系，一个口令进一个界面。想拉人一起用得先补权限模型。
- **不是流式输出**。结论是整段回来的；轨迹是实时流的。
- **没有长期记忆**。员工的人设是提示词，不会自己积累你的偏好。
- **Windows 没测过**。`run_shell` 走的是 `/bin/sh`，Windows 上会退化。
- **沙箱很浅**。只有路径围栏 + 命令黑名单 + 三个权限开关，不是一个真正的安全边界。别拿它跑不受信任的输入。

## 开源前你应该自己确认的事

- `data/` 没被提交（`git status` 里看不到它）
- API Key 没有硬编码在任何文件里
- 如果要给别人用，README 里写清「数据会发给你配置的模型服务商」——这是隐私问题，不是技术问题
